Política de Privacidad

Última actualización: noviembre de 2026

Creative Pocket es una aplicación educativa diseñada para facilitar el aprendizaje de diferentes disciplinas creativas mediante actividades y desafíos interactivos.

1. Información que recopilamos

Creative Pocket almacena localmente determinada información necesaria para el funcionamiento de la aplicación:

  • Nombre del usuario.
  • Actividades de aprendizaje completadas.
  • Puntos de experiencia (XP).
  • Identificadores de actividades recompensadas.

Esta información se guarda en el dispositivo mediante AsyncStorage. La contraseña introducida durante el registro no se se envía a servidores externos.

2. Almacenamiento y uso de los datos

Los datos se almacenan localmente en el dispositivo del usuario. Se utilizan exclusivamente para identificar el perfil local y conservar el progreso de aprendizaje.

La versión actual no utiliza un servidor propio para almacenar o procesar esta información.

3. Compartición de información

Creative Pocket no vende, comparte ni transmite a terceros los datos personales almacenados localmente.

No incorpora publicidad ni utiliza los datos almacenados para fines publicitarios.

4. Eliminación de datos y contacto

La información guardada localmente puede eliminarse al desinstalar la aplicación o borrar sus datos desde la configuración del dispositivo.
